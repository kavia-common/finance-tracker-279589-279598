# FinanceTracker Android (Kotlin + Jetpack Compose)

This module contains the Android application for FinanceTracker built with Kotlin and Jetpack Compose (Material3).

How to build:
- Using Gradle wrapper:
  - macOS/Linux: `./gradlew :app:assembleDebug`
  - Windows: `gradlew.bat :app:assembleDebug`

Requirements:
- JDK 17
- Android SDK with compileSdk 34 installed

Notes:
- Namespace and applicationId: `com.example.financetracker`
- Min SDK 24, Target SDK 34
- Compose compiler extension 1.5.14 (Kotlin 1.9.24)
